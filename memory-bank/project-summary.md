# Project Summary — Financial Metrics Dashboard

_Generated by AI assistant inspection, then independently validated against the
real codebase. Last updated: 2026-08-23._

## 1. Product Purpose

A single-page, dark-theme financial dashboard. On load, it fetches a year of
mock financial movements from a FastAPI backend, computes totals, and renders:

- 4 KPI cards: Total Income, Total Outcome, Profit, Profit Margin
- 2 line charts: Income vs. Outcome (monthly), Profit Margin % (monthly)

All data is synthetic — the backend generates 360 seeded-random movements
(`seed=42`) per request. There is no database, no real financial data source,
and no authentication. The UI is read-only; no filter controls are exposed,
even though the backend supports filtering.

## 2. Architecture

- React SPA (Vite dev server, port 5173) ↔ FastAPI backend (Uvicorn, port 8000)
- In dev/Docker Compose, Vite proxies `/api/*` requests to `http://backend:8000`
- Data flow: frontend calls `GET /api/metrics` → backend generates 360 mock
  movements → raw JSON returned → frontend computes KPIs and monthly
  aggregates client-side (`financial-utils.ts`) → renders KPI cards + charts
- 9 backend routes exist total; only `/api/metrics` is consumed by the
  frontend. The other 8 (`/health`, `/facets`, `/summary`, `/categories/top`,
  `/comparison`, `/alerts`, `/b2b`, `/b2c`) are implemented and tested but
  unused by the UI.

## 3. Tech Stack

**Frontend:** React 19, TypeScript ~6.0, Vite 8, Tailwind CSS 4, shadcn/ui,
lucide-react, Recharts, Vitest, ESLint.

**Backend:** Python 3.13, FastAPI, Pydantic, Uvicorn, debugpy, pytest/httpx
for testing.

**Infra:** Docker Compose orchestrating two services (frontend, backend),
each with its own Dockerfile.

## 5. Notable Patterns

- **Single-file backend** — no service/repository layers, no database.
- **Seeded random data, no persistence** — same 360 movements every run.
- **Two disconnected computation paths** — frontend computes KPIs client-side;
  backend has its own summary/comparison endpoints the frontend never calls.
- **Only 1 of 9 backend routes is used** by the frontend.
- **Dark mode is hardcoded**, not togglable — light theme CSS exists but is
  dead.
- **No routing or state management library** — single route, `useState`/`useEffect` only.
- **`mock-data.ts` is dead code.**
- **`AGENTS.md` pointed to directories that didn't exist yet** at time of
  writing (`.agents/rules`, `.agents/skills`, `memory-bank/`) — this project
  creates them.
